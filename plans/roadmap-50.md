# The Narrows Roadmap Index

The former “next 50” checklist mixed completed work, stale web assumptions, and
unfinished Godot features. It is superseded.

## Active execution plan

- [`../docs/superpowers/plans/2026-07-29-the-narrows-godot-completion.md`](../docs/superpowers/plans/2026-07-29-the-narrows-godot-completion.md)

The active plan contains 14 ordered tasks:

1. reconcile the product and engine source of truth;
2. add strict Godot verification and CI;
3. ship current branding with build provenance;
4. cut and instrument startup;
5. introduce a typed mission runtime;
6. author “Off the Boat” as a tutorial encounter;
7. add versioned, recoverable saves;
8. complete responsive UI and input;
9. port boat and street-race activities;
10. make police and civic AI readable;
11. author one New Bedford district;
12. finish accessibility/settings/audio fallbacks;
13. replace Act I placeholders with authored content;
14. certify and ship 1.0.

Only the active execution plan carries implementation checkboxes. Mark a task
complete only after its named automated and manual gates pass against the
Godot ship target and the deployed build SHA is recorded.
